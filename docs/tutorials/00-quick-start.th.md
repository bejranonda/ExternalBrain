# คู่มือเริ่มต้นใช้งาน — เชื่อมต่อเครื่องมือ AI กับ External Brain ใน 3 นาที

**ใช้เวลา:** ~3 นาที **สิ่งที่ต้องมี:** URL ของ Brain (เช่น `https://brain.autobahn.bot`) และบัญชีผู้ใช้ หรือรหัสวอเชอร์

> การแปลนี้จัดทำโดย AI และยังรอการตรวจทานจากเจ้าของภาษา ฉบับภาษาอังกฤษคือฉบับอ้างอิง: [00-quick-start.md](./00-quick-start.md)

---

> [!IMPORTANT]
> **เลือกทางเลือกการติดตั้งทางใดทางหนึ่งด้านล่าง (อย่าทำทั้งสองทาง):**
> - **ทางเลือกที่ 1 (แนะนำหากมีรหัสวอเชอร์)** — ตั้งค่าอัตโนมัติผ่าน AI แชท ใน 1 นาที
> - **ทางเลือกที่ 2 (เส้นทางมาตรฐานหากมีบัญชีผู้ใช้)** — ตั้งค่าผ่าน Web UI ใน 2 นาที

---

## ทางเลือกที่ 1 — ตั้งค่าอัตโนมัติด้วยรหัสวอเชอร์ (1 นาที)

ใช้ทางเลือกนี้หากเพื่อนร่วมทีมให้รหัสวอเชอร์หรือลิงก์เชิญแก่คุณ:

1. เปิด [`https://<your-brain>/start`](https://<your-brain>/start) ในเบราว์เซอร์แล้วใส่รหัสวอเชอร์ของคุณ
2. คัดลอกคำสั่ง (Prompt) ที่แสดงบนหน้าจอ ไปวางใน Claude Code, Cursor หรือ Windsurf เครื่องมือ AI ของคุณจะสร้างบัญชีและตั้งค่าการเชื่อมต่อ Brain ให้โดยอัตโนมัติ
3. **รีสตาร์ทเครื่องมือ AI ของคุณ** เพื่อให้โหลดการตั้งค่า MCP ใหม่

> **หมายเหตุเกี่ยวกับโทเคน:** โทเคนที่สร้างผ่านแชท AI จะมีอายุ 14 วัน และจำกัดการเข้าถึงเฉพาะการดึงข้อมูลพื้นฐานเพื่อความปลอดภัย คุณสามารถสร้างโทเคนถาวรได้ทุกเมื่อที่ **Settings → Tokens** ([`/settings/tokens`](/settings/tokens)) ดูรายละเอียดใน [บทเรียนที่ 04](./04-managing-tokens.md)

---

## ทางเลือกที่ 2 — ตั้งค่ามาตรฐานด้วยบัญชีผู้ใช้ (3 ขั้นตอน)

### ขั้นตอนที่ 1 — สร้างโทเคนและคัดลอกคำสั่ง

1. เข้าสู่ระบบเว็บแอป Brain → ไปที่ **Settings → Tokens** ([`/settings/tokens`](/settings/tokens))
2. กด **Create token** → ตั้งชื่อตามเครื่องของคุณ (`laptop`, `workstation`, `ci-runner`)
3. กดปุ่ม **Copy Command** บนหน้าจอสำเร็จ *(ปุ่มนี้จะคัดลอกคำสั่งที่ใส่โทเคนจริงและ URL ของคุณมาไว้ในคลิปบอร์ดเรียบร้อยแล้ว!)*

---

### ขั้นตอนที่ 2 — รันคำสั่งติดตั้งและรีสตาร์ทเครื่องมือ AI

1. เปิดเทอร์มินัลบนเครื่องของคุณ
2. **วางและรันคำสั่งจริงที่คุณคัดลอกมาจากคลิปบอร์ดในขั้นตอนที่ 1**

> [!WARNING]
> **ห้ามคัดลอกคำสั่งตัวอย่างด้านล่างนี้ไปวางในเทอร์มินัล** คำสั่งตัวอย่างด้านล่างเป็นเพียงข้อความจำลอง (`https://<your-brain>` และ `bp_...`) ให้ใช้วิธีวางคำสั่งจริงที่คุณคัดลอกจากหน้าจอเว็บแอปในขั้นตอนที่ 1 เท่านั้น!

```bash
# ตัวอย่างเท่านั้น — ห้ามคัดลอกบล็อกนี้! ให้วางคำสั่งจริงที่คัดลอกมาจากขั้นตอนที่ 1
curl -fsSL https://<your-brain>/api/onboard.sh | bash -s 'bp_…your_token…' --client claude-code
```

```powershell
# ตัวอย่างเท่านั้น (Windows PowerShell) — ให้วางคำสั่งจริงที่คัดลอกมาจากขั้นตอนที่ 1
iwr https://<your-brain>/api/onboard.ps1 -UseBasicParsing | iex
Install-Brain -Token 'bp_…your_token…' -Client claude-code
```

3. **รีสตาร์ทเครื่องมือ AI ของคุณ** *(จำเป็น: เครื่องมือ AI อย่าง Claude Code, Cursor, และ Windsurf จะค้นหาเซิร์ฟเวอร์ MCP ใหม่เฉพาะตอนเริ่มโปรแกรมเท่านั้น)*

> ต้องการตรวจสอบสคริปต์ก่อนรัน? ดู [บทเรียนที่ 01 — การตั้งค่าเชิงลึก](./01-getting-started.md)

### ขั้นตอนที่ 3 — ลองสนทนาครั้งแรก (ตัวอย่างการใช้งานจริง)

คุณพูดคุยกับเครื่องมือ AI ด้วยภาษาธรรมชาติทั่วไป — ไม่ต้องใช้คำสั่งพิเศษ:

#### ตัวอย่างบทสนทนาจริง (ภาพการใช้งานในชีวิตประจำวัน)

```text
You:     I need to refactor the auth middleware to use the credentials adapter.
Claude:  [opens session, retrieves matching rules]
         Two of your rules apply here: session tokens bind at start, and
         credential checks belong at the route handler.

You:     no — we moved credential checks to the repository layer last month.
Claude:  Noted, updating code to use the repository layer.

You:     that worked, we're done.
Claude:  [closes session & extracts new rules]
         Saved rule: "Credential checks live at the repository layer, not the route handler."
```

#### ตารางสรุปประโยคที่ใช้บ่อย

| พูดว่า… | เกิดอะไรขึ้นในชีวิตจริง | ทำไมถึงสำคัญ |
|---|---|---|
| *"ask the brain what it knows about this project"* | ยืนยันการเชื่อมต่อและแสดงกฎของโปรเจกต์ | พิสูจน์ว่า AI ของคุณสื่อสารกับ Brain ได้ |
| *"remember this: we use pgvector, not Pinecone"* | บันทึกกฎถาวรไว้ใต้ **Skills** | ป้องกันไม่ให้ AI ทำผิดพลาดเรื่องเดิมซ้ำอีก |
| *"no — we moved that check to the route handler last month"* | แก้ไขข้อผิดพลาดระหว่างเซสชัน | สอนให้ Brain ยกเลิกคำแนะนำที่ล้าสมัย |
| *"we decided to use Redis for sessions, not Postgres"* | บันทึกเป็น **Decision** ของโปรเจกต์ | ความจำร่วมของทีม ไม่ถูกลบหรือจางหาย |
| *"ask the oracle: how did we solve the migration ordering?"* | สรุปคำตอบพร้อมอ้างอิงแหล่งที่มา `[^K1]`, `[^S2]` | ตอบคำถามโดยใช้ประวัติของโปรเจกต์คุณเอง |
| *"that worked"* / *"we're done"* / *"ship it"* | **ปิดเซสชันและดึงสkillใหม่** | **พฤติกรรมสำคัญ:** เซสชันที่ไม่ถูกปิดจะไม่เกิดการเรียนรู้! การปิดเซสชันคือหัวใจหลักที่ทำให้ Brain ฉลาดขึ้น |

## ตรวจสอบผลการทำงาน

```bash
# ตรวจสอบว่า Claude Code มองเห็นเซิร์ฟเวอร์ brain หรือไม่
claude mcp list | grep brain
```

ในเครื่องมือ AI ของคุณ ลองถาม: *"ask the brain what it knows about this project"* หาก AI ตอบกลับด้วยกฎของโปรเจกต์ (หรือบอกว่ายังไม่มีกฎ) แสดงว่า Brain ของคุณพร้อมใช้งานแล้ว!

### การแก้ไขปัญหาเบื้องต้น

| อาการ | สาเหตุ | วิธีแก้ไข |
|---|---|---|
| เครื่องมือ AI มองไม่เห็น Brain | ไม่ได้รีสตาร์ทหลังขั้นตอนที่ 2 | ปิดและเปิดเทอร์มินัล/โปรแกรมใหม่ |
| `401 Unauthorized` | โทเคนหมดอายุ ยกเลิก หรือไปคัดลอกคำสั่งตัวอย่างจากคู่มือ | สร้างโทเคนใหม่ที่ `/settings/tokens` และวางคำสั่งจริงจากเว็บแอป |
| เชื่อมต่อแล้ว แต่ Skills ยังว่างเปล่า | ไม่เคยปิดเซสชัน | พูดว่า *"we're done"* เมื่อทำงานเสร็จ |
| แก้ไข `~/.claude/mcp.json` เองแล้วไม่เกิดอะไรขึ้น | แก้ผิดไฟล์ | Claude Code อ่านจาก `~/.claude.json` |
