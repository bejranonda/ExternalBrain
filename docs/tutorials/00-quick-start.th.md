# คู่มือเริ่มต้นใช้งาน — จากศูนย์สู่ Brain ที่เรียนรู้ได้

**ใช้เวลา:** ประมาณ 5 นาที **สิ่งที่ต้องมี:** URL ของ Brain (เช่น `https://brain.autobahn.bot`) และบัญชีผู้ใช้หรือคำเชิญ

สามขั้นตอน สร้างโทเคน รันคำสั่งเดียว แล้วคุยกับมันตามปกติ

> การแปลนี้จัดทำโดย AI และยังรอการตรวจทานจากเจ้าของภาษา ฉบับภาษาอังกฤษคือฉบับอ้างอิง: [00-quick-start.md](./00-quick-start.md)

---

## ทางลัด — มีรหัสวอเชอร์? ข้ามไปที่ `/start`

เปิด `https://<your-brain>/start` วางรหัสของคุณ แล้วคัดลอกคำสั่งที่ได้ไปวางใน
Claude Code, Cursor หรือเครื่องมือ AI ใดก็ได้ที่ดึงข้อมูลจาก URL ได้ AI ของคุณจะสร้างบัญชี
สร้างโทเคน และรันคำสั่งติดตั้งให้ — **จากนั้นให้รีสตาร์ทเครื่องมือ AI**
เพราะค่าตั้งค่า MCP จะถูกอ่านเฉพาะตอนเริ่มโปรแกรมเท่านั้น

โทเคนที่ได้จะถูกจำกัดสิทธิ์ไว้ (14 วัน เรียกใช้ Oracle ไม่ได้) เพราะรหัสนั้นผ่านหน้าต่างแชทมา
สร้างโทเคนแบบเต็มได้ภายหลังที่ **Settings → Tokens**

ไม่มีรหัสวอเชอร์ หรือได้ `agentic_onboarding_disabled`? ทำตามขั้นตอนที่ 1 ด้านล่างต่อไป

---

## ขั้นตอนที่ 1 — สร้างโทเคน

1. เข้าสู่ระบบแล้วไปที่ **Settings → Tokens** (`/settings/tokens`)
2. กด **Create token** แล้วตั้งชื่อตาม*เครื่อง* ไม่ใช่ชื่อคุณ เช่น `laptop`, `work-desktop`, `ci-runner` เพราะการเพิกถอนสิทธิ์ทำทีละเครื่อง ชื่อแบบนี้จึงทำให้การเพิกถอนมีความหมายจริงในภายหลัง
3. คัดลอกค่า `bp_…`

> **โทเคนจะแสดงเพียงครั้งเดียว** ฐานข้อมูลเก็บเฉพาะค่าแฮช SHA-256 ไม่มีปุ่มดูย้อนหลัง และทีมสนับสนุนก็กู้คืนให้ไม่ได้ ถ้าทำหาย ให้สร้างใหม่แล้วเพิกถอนอันเดิม

จากนั้นหน้าจอจะแสดงคำสั่งติดตั้งที่ใส่โทเคนของคุณไว้ให้แล้ว คำสั่งนั้นคือขั้นตอนที่ 2 — คัดลอกแล้วข้ามไปได้เลย

---

## ขั้นตอนที่ 2 — เชื่อมเครื่องมือ AI ของคุณ

คำสั่งเดียว ใช้ได้กับทุกเครื่องมือ ค่าเริ่มต้นของ `--client` คือ `claude-code`

```bash
# macOS / Linux / WSL / Git Bash
curl -fsSL https://<your-brain>/api/onboard.sh | bash -s 'bp_…' --client claude-code
```

```powershell
# Windows PowerShell 5.1 ขึ้นไป
iwr https://<your-brain>/api/onboard.ps1 -UseBasicParsing | iex
Install-Brain -Token 'bp_…' -Client claude-code
```

### เลือกค่า `--client` ของคุณ

| เครื่องมือ | `--client` | ข้อควรรู้ |
|---|---|---|
| Claude Code | `claude-code` | ติดตั้งสกิลของ Brain ให้ด้วย |
| Claude Desktop | `claude-desktop` | ต้องมี Node และต้อง**ปิดแอปทั้งหมด**หลังติดตั้ง แค่ปิดหน้าต่างไม่พอ |
| Cursor | `cursor` | |
| Windsurf | `windsurf` | |
| Google Antigravity | `antigravity` | ไฟล์ตั้งค่าเดียวใช้ได้ทั้ง IDE และ CLI |
| VS Code + Copilot | `vscode` | ต้องรันจากโฟลเดอร์รากของโปรเจกต์ เพราะเขียนไฟล์ `./.vscode/mcp.json` |
| GitHub Copilot CLI | `copilot-cli` | |
| OpenAI Codex | `codex` | จะแสดงบรรทัด `export BRAIN_TOKEN=…` ด้วย **ต้องใส่ในโปรไฟล์เชลล์ ไม่อย่างนั้น Codex จะได้ 401** |
| เครื่องมืออื่น ๆ | `generic` | เพิ่ม `--config-path <ไฟล์>` แล้วระบบจะเขียนไฟล์นั้นให้ |

JetBrains / Visual Studio / Eclipse / Xcode ไม่มีตำแหน่งไฟล์ตั้งค่าที่แน่นอน จึงต้องคัดลอก JSON จากหน้าสร้างโทเคนไปวางเอง

### คำสั่งนั้นทำอะไรบ้าง

1. **เขียนไฟล์ตั้งค่า** โดยใช้คำสั่ง `mcp add` ของเครื่องมือนั้นเองถ้ามี ถ้าไม่มีก็จะ**ผสาน**เข้าไปในไฟล์เดิม เซิร์ฟเวอร์ MCP ตัวอื่นของคุณยังอยู่ครบ และมีการสำรองไฟล์ไว้ก่อน
2. **พิสูจน์ว่าใช้งานได้จริง** ด้วยการเชื่อมต่อ MCP และเรียกเครื่องมือจริงผ่านเครือข่ายและระบบยืนยันตัวตนของคุณ นี่คือเหตุผลที่มันบอกว่าสำเร็จได้อย่างซื่อสัตย์ เพราะการเขียนไฟล์ลงดิสก์ไม่ได้พิสูจน์ว่าโทเคนเรียกอะไรได้จริง
3. **บันทึกเซสชันแรก** เพื่อให้แดชบอร์ดไม่ว่างเปล่า

**จากนั้นให้รีสตาร์ตเครื่องมือ AI ของคุณ** ทุกเครื่องมืออ่านไฟล์ตั้งค่า MCP ตอนเริ่มโปรแกรมเท่านั้น — นี่คือสาเหตุอันดับหนึ่งของอาการ "ติดตั้งแล้วแต่ไม่มีอะไรเกิดขึ้น"

อยากอ่านสคริปต์ก่อนรัน?

```bash
curl -fsSL https://<your-brain>/api/onboard.sh -o /tmp/brain-install.sh
less /tmp/brain-install.sh
bash /tmp/brain-install.sh 'bp_…' --client cursor
```

## ขั้นตอนที่ 3 — คุยกับมัน

คุณไม่ต้องเรียกชื่อเครื่องมือใด ๆ แค่พูดตามปกติ แล้วสกิลที่ติดตั้งไว้จะบอก AI เองว่าควรเรียกใช้อะไร

| เมื่อคุณพูดว่า… | สิ่งที่เกิดขึ้น |
|---|---|
| *(เริ่มงานจริงจังใด ๆ ก็ตาม)* | เปิดเซสชัน แล้วส่งกฎเก่าที่เกี่ยวข้องเข้าไปให้ |
| "จำไว้นะ: เราใช้ pgvector ไม่ใช่ Pinecone" | บันทึกเป็นกฎ และจะปรากฏในหน้า **Skills** |
| "ถาม oracle หน่อย: ตอนนั้นเราแก้ปัญหาลำดับ migration ยังไง" | คำตอบที่เรียบเรียงแล้ว **พร้อมการอ้างอิง** |
| "หากฎเกี่ยวกับ prisma migrations" | ผลลัพธ์ที่ใกล้เคียงตามความหมาย ทันทีและฟรี |
| "สัปดาห์ที่แล้วทำอะไรเรื่อง billing ไว้บ้าง" | เซสชันเก่าที่ตรงกับคำเหล่านั้น |
| **"ใช้ได้แล้ว" / "เสร็จแล้ว" / "ปิดงาน"** | **ปิดเซสชัน — นี่คือสิ่งที่ทำให้มันเรียนรู้** |

### นิสัยเดียวที่สำคัญที่สุด

**ปิดเซสชันของคุณ** พูดว่า *"ใช้ได้แล้ว"* หรือ *"เสร็จแล้ว"* ทุกครั้งที่ทำงานจบ

เซสชันที่ไม่ได้ปิดจะไม่สอนอะไร Brain เลย เพราะกระบวนการสกัดความรู้จะทำงานตอนปิดเซสชันเท่านั้น นี่คือสาเหตุอันดับหนึ่งที่ Brain ยังว่างเปล่าหลังใช้งานจริงมาทั้งสัปดาห์ ทุกอย่างที่เหลือเป็นทางเลือก ยกเว้นข้อนี้

### ตัวอย่างเซสชันตั้งแต่ต้นจนจบ

```
คุณ     ผมต้องรีแฟกเตอร์ auth middleware ให้ใช้ credentials adapter ตัวใหม่
Claude  [เปิดเซสชัน ดึงกฎที่เกี่ยวข้องขึ้นมา]
        มีกฎของคุณสองข้อที่ใช้ได้ตรงนี้: เซสชันจะผูกค่าตอนเริ่ม
        และการตรวจ credential อยู่ที่ชั้น repository

คุณ     ไม่ใช่ — เราย้ายการตรวจนั้นไป route handler เมื่อเดือนที่แล้ว
Claude  รับทราบ กำลังปรับให้

คุณ     ใช้ได้แล้ว เสร็จแล้วครับ
Claude  [ปิดเซสชันพร้อมสิ่งที่เรียนรู้]
        บันทึกแล้ว: "การตรวจ credential อยู่ที่ route handler
        ไม่ใช่ชั้น repository — ย้ายเมื่อ 2026-07"
```

การแก้ครั้งนั้นถูกจำไว้ถาวรแล้ว เดือนหน้าบนเครื่องอื่น มันจะถูกส่งมาให้ก่อนที่คุณจะต้องนึกออกเอง

### วิธีถามให้ได้คำตอบดี ๆ

- **"หากฎเกี่ยวกับ X"** — ทันที ฟรี ไม่เรียกโมเดล ใช้ทุกครั้งที่คุณกำลังจะคิดเรื่องที่เคยตัดสินใจไปแล้วซ้ำอีก
- **"ถาม oracle หน่อย: …"** — ช้ากว่าและมีค่าใช้จ่าย แต่ได้คำตอบที่เรียบเรียงพร้อมการอ้างอิง ใช้เมื่อต้องการเหตุผล ไม่ใช่แค่รายการ
- **อย่า**ถาม Oracle เรื่องการเขียนโปรแกรมทั่วไป มันคือความจำของโปรเจกต์คุณ ไม่ใช่อินเทอร์เน็ต

## ตรวจสอบว่าใช้งานได้

```bash
claude mcp list | grep brain
```

จากนั้นลองพิมพ์ในเครื่องมือของคุณว่า *"ถาม brain หน่อยว่ารู้อะไรเกี่ยวกับโปรเจกต์นี้บ้าง"* ถ้ามันตอบอะไรกลับมาได้ แปลว่าวงจรทำงานแล้ว

| อาการ | สาเหตุ |
|---|---|
| เครื่องมือไม่เห็น Brain | ยังไม่ได้รีสตาร์ตหลังติดตั้ง |
| ได้ 401 ทุกครั้ง | โทเคนถูกเพิกถอน หมดอายุ หรือมาจาก Brain คนละตัว |
| เฉพาะ Codex ที่ได้ 401 | ไม่ได้ตั้ง `BRAIN_TOKEN` ในโปรไฟล์เชลล์ |
| เชื่อมต่อได้ แต่หน้า Skills ยังว่าง | ไม่เคยปิดเซสชัน — ลองพูดว่า "เสร็จแล้ว" |
| แก้ไฟล์ `~/.claude/mcp.json` แล้วไม่มีอะไรเปลี่ยน | ผิดไฟล์ Claude Code อ่าน `~/.claude.json` |
