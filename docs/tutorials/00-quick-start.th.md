# คู่มือเริ่มต้นใช้งาน — จากศูนย์สู่ Brain ที่เรียนรู้ได้

**ใช้เวลา:** ประมาณ 5 นาที **สิ่งที่ต้องมี:** URL ของ Brain (เช่น `https://brain.autobahn.bot`) และบัญชีผู้ใช้ หรือรหัสวอเชอร์

สองทางเลือก — เลือกทางใดทางหนึ่ง: ให้ AI ของคุณตั้งค่าให้ด้วยรหัสวอเชอร์ หรือทำเอง
สามขั้นตอน: เข้าสู่ระบบ สร้างโทเคน รันคำสั่งเดียว

> การแปลนี้จัดทำโดย AI และยังรอการตรวจทานจากเจ้าของภาษา ฉบับภาษาอังกฤษคือฉบับอ้างอิง: [00-quick-start.md](./00-quick-start.md)

---

## มีรหัสวอเชอร์? ให้ AI ของคุณตั้งค่าให้

เปิด [`https://<your-brain>/start`](https://<your-brain>/start) วางรหัสของคุณ แล้วคัดลอกคำสั่งที่ได้ไปวางใน
Claude Code, Cursor หรือเครื่องมือ AI ใดก็ได้ที่ดึงข้อมูลจาก URL ได้ AI ของคุณจะสร้างบัญชี
สร้างโทเคน และรันคำสั่งติดตั้งให้ — **จากนั้นให้รีสตาร์ทเครื่องมือ AI**
เพราะค่าตั้งค่า MCP จะถูกอ่านเฉพาะตอนเริ่มโปรแกรมเท่านั้น

โทเคนที่ได้จะถูกจำกัดสิทธิ์ไว้ (14 วัน เรียกใช้ Oracle ไม่ได้) เพราะรหัสนั้นผ่านหน้าต่างแชทมา
— รายละเอียดใน [บทเรียนที่ 04](./04-managing-tokens.md) สร้างโทเคนแบบเต็มได้ภายหลังที่
**Settings → Tokens**

มีบัญชีอยู่แล้ว หรือได้ `agentic_onboarding_disabled`? ทำตามขั้นตอนที่ 1 ด้านล่างต่อไป
ไม่มีทั้งรหัสวอเชอร์และบัญชี? ขอรหัสวอเชอร์จากผู้ดูแล Brain นี้ — ดูที่ [`/start`](/start)

---

## ขั้นตอนที่ 1 — สร้างโทเคน

1. เข้าสู่ระบบ → **Settings → Tokens** ([`/settings/tokens`](/settings/tokens))
2. กด **Create token** แล้วตั้งชื่อตาม*เครื่อง* เช่น `laptop`, `ci-runner`
3. คัดลอกค่า `bp_…` — แสดงเพียงครั้งเดียว และหน้าจอถัดไปมีคำสั่งติดตั้งเตรียมไว้ให้แล้ว รายละเอียด (การหมุนเวียน ขอบเขต การเพิกถอน): [บทเรียนที่ 04](./04-managing-tokens.md)

---

## ขั้นตอนที่ 2 — เชื่อมเครื่องมือ AI ของคุณ

คำสั่งเดียว ใช้ได้กับทุกเครื่องมือ ค่าเริ่มต้นของ `--client` คือ `claude-code`

```bash
# macOS / Linux / WSL / Git Bash
curl -fsSL https://<your-brain>/api/onboard.sh | bash -s 'bp_…' --client claude-code
```

```powershell
# Windows PowerShell 5.1 ขึ้นไป
iwr https://<your-brain>/api/onboard.ps1 -UseBasicParsing | iex
Install-Brain -Token 'bp_…' -Client claude-code
```

### เลือกค่า `--client` ของคุณ

| เครื่องมือ | `--client` | ข้อควรรู้ |
|---|---|---|
| Claude Code | `claude-code` | ติดตั้งสกิลของ Brain ให้ด้วย |
| Claude Desktop | `claude-desktop` | ต้องมี Node และต้อง**ปิดแอปทั้งหมด**หลังติดตั้ง แค่ปิดหน้าต่างไม่พอ |
| Cursor | `cursor` | |
| Windsurf | `windsurf` | |
| Google Antigravity | `antigravity` | ไฟล์ตั้งค่าเดียวใช้ได้ทั้ง IDE และ CLI |
| VS Code + Copilot | `vscode` | ต้องรันจากโฟลเดอร์รากของโปรเจกต์ เพราะเขียนไฟล์ `./.vscode/mcp.json` |
| GitHub Copilot CLI | `copilot-cli` | |
| OpenAI Codex | `codex` | จะแสดงบรรทัด `export BRAIN_TOKEN=…` ด้วย **ต้องใส่ในโปรไฟล์เชลล์ ไม่อย่างนั้น Codex จะได้ 401** |
| เครื่องมืออื่น ๆ | `generic` | เพิ่ม `--config-path <ไฟล์>` แล้วระบบจะเขียนไฟล์นั้นให้ |

JetBrains / Visual Studio / Eclipse / Xcode ไม่มีตำแหน่งไฟล์ตั้งค่าที่แน่นอน จึงต้องคัดลอก JSON จากหน้าสร้างโทเคนไปวางเอง

**จากนั้นให้รีสตาร์ตเครื่องมือ AI ของคุณ** ทุกเครื่องมืออ่านไฟล์ตั้งค่า MCP ตอนเริ่มโปรแกรมเท่านั้น — นี่คือสาเหตุอันดับหนึ่งของอาการ "ติดตั้งแล้วแต่ไม่มีอะไรเกิดขึ้น"

อยากรู้ว่าคำสั่งนี้ทำอะไรบ้าง หรืออยากอ่านสคริปต์ก่อนรัน? [บทเรียนที่ 01](./01-getting-started.md) อธิบายไว้ทีละขั้นตอน

## ขั้นตอนที่ 3 — คุยกับมัน

ไม่ต้องจำชื่อเครื่องมือใด ๆ แค่พูดตามปกติ ไม่ว่าใน Claude Code, Cursor, Windsurf หรือ MCP ใดก็ตาม — สกิลจะเลือกเรียก `brain_*` ที่ถูกต้องเอง

**พิสูจน์ว่าเชื่อมต่อแล้ว**
| เมื่อคุณพูดว่า… | สิ่งที่เกิดขึ้น |
|---|---|
| "ถาม brain หน่อยว่ารู้อะไรเกี่ยวกับโปรเจกต์นี้บ้าง" | ฟรี ทันที — พิสูจน์ว่าเชื่อมต่อแล้ว |

**สอนบางอย่างให้มัน**
| เมื่อคุณพูดว่า… | สิ่งที่เกิดขึ้น |
|---|---|
| "จำไว้นะ: เราใช้ pgvector ไม่ใช่ Pinecone" | บันทึกเป็นกฎ และจะปรากฏในหน้า **Skills** |
| "ไม่ใช่ — เราย้ายการตรวจนั้นไป route handler เมื่อเดือนที่แล้ว" | แก้ไขกลางเซสชัน สอนให้มันเลิกใช้คำแนะนำเก่าที่ล้าสมัย |
| "เราตัดสินใจใช้ Redis เก็บเซสชัน ไม่ใช่ Postgres" | บันทึกเป็นการตัดสินใจของโปรเจกต์ (ใช้ร่วมกันได้ ไม่หมดอายุ) |

**เรียกคืนความจำ — ทันที ฟรี ไม่เรียกโมเดล**
| เมื่อคุณพูดว่า… | สิ่งที่เกิดขึ้น |
|---|---|
| "หากฎเกี่ยวกับ prisma migrations" | ผลลัพธ์ที่ใกล้เคียงตามความหมาย |
| "สัปดาห์ที่แล้วทำอะไรเรื่อง billing ไว้บ้าง" | เซสชันเก่าที่ตรงกับคำเหล่านั้น |

**ถาม Oracle — ช้ากว่า มีค่าใช้จ่าย แต่ได้คำตอบพร้อมการอ้างอิง**
| เมื่อคุณพูดว่า… | สิ่งที่เกิดขึ้น |
|---|---|
| "ถาม oracle หน่อย: ตอนนั้นเราแก้ปัญหาลำดับ migration ยังไง" | คำตอบที่เรียบเรียงแล้ว อ้างอิงถึงเซสชันต้นทาง |
| ✗ "ถาม oracle หน่อย: flexbox ทำงานยังไง" | ใช้ผิดวัตถุประสงค์ — มันคือความจำของโปรเจกต์คุณ ไม่ใช่อินเทอร์เน็ต |

**ปิดวงจร — นิสัยเดียวที่สำคัญที่สุด**
| เมื่อคุณพูดว่า… | สิ่งที่เกิดขึ้น |
|---|---|
| "ใช้ได้แล้ว" / "เสร็จแล้ว" / "ปิดงาน" | **ปิดเซสชัน — นี่คือสิ่งที่ทำให้มันเรียนรู้** เซสชันที่ไม่ได้ปิดจะไม่สอนอะไร Brain เลย นี่คือสาเหตุอันดับหนึ่งที่ Brain ยังว่างเปล่าหลังใช้งานจริงมาทั้งสัปดาห์ |

หมวดหมู่เพิ่มเติมและตัวอย่างแบบเต็ม: [บทเรียนที่ 01](./01-getting-started.md), [บทเรียนที่ 02 — การถาม Oracle](./02-asking-the-oracle.md), [บทเรียนที่ 03 — การสอนความรู้](./03-teaching-knowledge.md)

## ตรวจสอบว่าใช้งานได้

```bash
claude mcp list | grep brain
```

จากนั้นลองพิมพ์ในเครื่องมือของคุณว่า *"ถาม brain หน่อยว่ารู้อะไรเกี่ยวกับโปรเจกต์นี้บ้าง"* ถ้ามันตอบอะไรกลับมาได้ แปลว่าวงจรทำงานแล้ว

| อาการ | สาเหตุ |
|---|---|
| เครื่องมือไม่เห็น Brain | ยังไม่ได้รีสตาร์ตหลังติดตั้ง |
| ได้ 401 ทุกครั้ง | โทเคนถูกเพิกถอน หมดอายุ หรือมาจาก Brain คนละตัว |
| เฉพาะ Codex ที่ได้ 401 | ไม่ได้ตั้ง `BRAIN_TOKEN` ในโปรไฟล์เชลล์ |
| เชื่อมต่อได้ แต่หน้า Skills ยังว่าง | ไม่เคยปิดเซสชัน — ลองพูดว่า "เสร็จแล้ว" |
| แก้ไฟล์ `~/.claude/mcp.json` แล้วไม่มีอะไรเปลี่ยน | ผิดไฟล์ Claude Code อ่าน `~/.claude.json` |
